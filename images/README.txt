ARENA DAS CAMISAS — FOTOS DOS PRODUTOS

Como usar:
1. Cada pasta abaixo representa um produto.
2. Coloque 3 fotos em cada pasta:
   - frente.jpg  = foto principal, modelo vestindo a camisa
   - costas.jpg  = foto das costas
   - detalhe.jpg = foto de detalhe/tecido/escudo
3. Não altere os nomes dos arquivos.
4. Prefira JPG ou JPEG.
5. Para melhor resultado, use fotos verticais e com boa iluminação.

Exemplo:
images/flamengo-home-25-26/frente.jpg
images/flamengo-home-25-26/costas.jpg
images/flamengo-home-25-26/detalhe.jpg

Se uma foto ainda não existir, o site mostra automaticamente a camisa ilustrada como substituta.
